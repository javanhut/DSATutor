Watch the code run, then solve it yourself.

Every chapter explains why a pattern works, lets you step through it line by line with the variables in view, and ends with problems checked against hidden tests.

    Read

    Each chapter opens with the idea, why it works, and the mistakes people usually make with it.

    Check

    Worked examples reveal one subgoal at a time, then fill-in-the-blank code and recall questions test what stuck.

  4. 04

    Practise

    Problems run against hidden tests. The ones you solve come back for review on a schedule.
